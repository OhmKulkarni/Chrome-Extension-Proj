This page tests the Chrome extension's ability to group iframe-based third-party requests under the correct main domain.

📊 Test Objective

Expected Behavior: Network requests from iframes should be grouped under the main page domain (localhost) in the extension dashboard, not as separate domains.

🎯 What to look for:
  • Open the extension dashboard after running tests
  • Check that iframe requests appear under "localhost" or the main domain
  • Verify that tabUrl in the logs shows the main page URL, not the iframe URL
