🧪 Settings Feature Testing Suite

Comprehensive testing for all implemented network interception settings.

📋 Pre-Test Setup

  1. Open Extension Settings: Right-click extension → Options
  2. Enable Features: Turn ON all toggles you want to test
  3. Open Popup: Ensure Global Power + Site Toggle are ON
  4. Enable Logging: Turn ON network/error/token logging in popup
  5. Open Dashboard: Keep dashboard open to monitor results

1. Network Monitoring Control

Control: Main toggle removed from settings - managed via popup/dashboard only

2. Tab-Specific Controls

Tests: `networkInterception.tabSpecific.enabled` setting

Manual Test: Use popup to toggle the blue "Site Toggle" on/off while generating requests below.

3. Noise/Telemetry Filtering

Tests: `networkInterception.privacy.filterNoise` setting

4. URL Pattern Filtering

Tests: `networkInterception.urlPatterns.enabled` setting

Setup: Add pattern like `https://httpbin.org/*` in settings to test this feature.

5. Console Error Logging

Tests: `errorLogging.enabled` and severity filtering

6. Token Detection & Display

Tests: Token detection and `tokenLogging.showFullHash` setting

7. Body Capture Configuration

Tests: `bodyCapture.mode` setting (UI only - no implementation)
