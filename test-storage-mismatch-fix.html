✅ Critical Storage Mismatch Fix Applied!

🎯 Root Cause Found & Fixed

The Issue: Storage location mismatch between popup and background script

  • ❌ Popup was saving to: IndexedDB via StorageService
  • ❌ Background was reading from: chrome.storage.local
  • ✅ Fixed: Both now use chrome.storage.local

Changes Made:

// POPUP SAVE (before) await storageService.set({ extensionEnabled: newState }); // IndexedDB // POPUP SAVE (after) await chrome.storage.local.set({ extensionEnabled: newState }); // chrome.storage.local // POPUP LOAD (before) const result = await storageService.get(['extensionEnabled']); // IndexedDB // POPUP LOAD (after) const result = await chrome.storage.local.get(['extensionEnabled']); // chrome.storage.local
