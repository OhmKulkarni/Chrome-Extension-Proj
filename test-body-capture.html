🔍 Network Body Capture Test

This page tests if request/response bodies are being captured by the extension's network interceptor.

📤 POST Request with Body Test

Tests capturing of request body data

📥 GET Request with Response Body

Tests capturing of response body data

🔄 Large JSON Request/Response

Tests body capture with larger payloads

📊 Instructions

After running the tests:

  1. Open the Chrome Extension Dashboard
  2. Go to the Network Requests table
  3. Double-click on any of the test requests
  4. Click the "Body" tab in the detail viewer
  5. You should see both request and response body content

Expected Results:

  • POST requests should show the JSON request body
  • All requests should show the JSON response body
  • Bodies should be properly formatted and copyable
