# Copilot Instructions for Chrome Extension Project

## 📋 Core Instructions

**ALWAYS** reference and maintain the `project-structure-reference.md` file when working in this workspace.

### 🔧 Required Actions After ANY File Changes:

1. **File Operations**: When you add, delete, rename, or significantly modify files (>10KB changes):
   - Update the file listing in `project-structure-reference.md`
   - Update file sizes if changed significantly
   - Note any new empty files or potential corruption

2. **Architecture Changes**: When modifying the modular structure:
   - Update the architecture overview section
   - Verify module dependencies are documented correctly
   - Check for any new or removed modules

3. **Build System Changes**: When modifying configuration files:
   - Update the core configuration files section
   - Note any new build artifacts or outputs

### 🚨 Corruption Detection Protocol

**Before starting work**:
- Check if file counts match the reference (should be ~152 files after cleanup)
- Verify critical module files are present and properly sized
- Alert if any core files are 0 KB when they shouldn't be

**During work**:
- Monitor for unexpected empty files
- Watch for files that suddenly lose content
- Flag any unusual file size changes

**Critical Architecture Files** (must never be 0 KB):

### 🔄 Update Triggers

Update `project-structure-reference.md` when:
- Adding new modules or components
- Deleting unused files
- Restructuring directories
- Adding new configuration files
- Significant size changes in core files (>5 KB difference)

### 🖥️ PowerShell Commands for Reference Updates

**To get complete file structure with sizes (for updating reference file):**
```powershell
Get-ChildItem -Recurse -Force | Where-Object { $_.FullName -notmatch 'node_modules|\.git|dist|\.vscode' } | Sort-Object FullName | ForEach-Object { $relativePath = $_.FullName.Replace((Get-Location).Path, '').TrimStart('\'); if ($_.PSIsContainer) { " $relativePath/" } else { $size = [math]::Round($_.Length / 1KB, 1); " $relativePath ($size KB)" } }
```

**To get updated file count:**
```powershell
$fileCount = (Get-ChildItem -Recurse -Force | Where-Object { -not $_.PSIsContainer -and $_.FullName -notmatch 'node_modules|\.git|dist|\.vscode' } | Measure-Object).Count; Write-Host "Updated file count: $fileCount"
```

**To identify empty files (0 KB) for cleanup:**
```powershell
Get-ChildItem -Recurse | Where { $_.Length -eq 0 -and !$_.PSIsContainer } | Select FullName
```

**To check specific files for corruption/empty status:**
```powershell
Get-Item "src\background\background-controller.ts", "src\content\content-modular.ts", "src\manifest.json" | Select Name, Length
```

### 💡 Best Practices

1. **File Integrity**: Always verify file contents match expected sizes
2. **Module Tracking**: Keep module count and dependencies current
3. **Placeholder Management**: Document which 0 KB files are intentional
4. **Size Monitoring**: Track significant changes in large files (ChartComponents.tsx, dashboard files)
