🔍 The Missing Timing Phase - Request Waiting

🕐 What is "Request Waiting" Time?

Request Waiting = requestStart - connectEnd

This is the time between when the connection is established and when the actual HTTP request starts sending. This can include:

  • HTTP/2 Stream Setup - Protocol negotiation
  • Connection Pool Management - Browser managing connection reuse
  • Request Queuing - Waiting for available connection slot
  • Browser Throttling - Request prioritization delays
  • Keep-Alive Processing - Connection state verification

🔍 When Request Waiting Time Appears

✅ Common Scenarios:

  • HTTP/2 sites - Stream multiplexing setup
  • Keep-alive connections - Connection validation
  • Busy servers - Request queuing
  • Browser throttling - Priority management
  • Connection pooling - Socket management

🔧 Technical Details:

  • 1-10ms: Normal HTTP/2 overhead
  • 10-50ms: Connection pool management
  • 50ms+: Request queuing or throttling
  • 0ms: Perfect connection timing (rare)
