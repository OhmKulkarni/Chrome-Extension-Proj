🔄 Dynamic Toggle Test

This page tests whether the extension responds to toggle changes without requiring a page refresh.

📋 Test Instructions

1 Load Extension: Make sure the extension is installed and working
2 Open Popup: Click the extension icon to open the popup
3 Verify States: Ensure Global Power (red) = ON, Site Toggle (blue) = ON
4 Enable Logging: Turn ON all three logging toggles (green/yellow switches)
5 Test Activity: Click "Generate Test Activity" below to verify logging works
6 Disable Site: Turn OFF the blue "Site Toggle" in popup
7 Test Disabled: Click test buttons again - should see no activity
8 Enable Site: Turn ON the blue "Site Toggle" again (WITHOUT refreshing page)
9 Test Restored: Click test buttons - should work immediately!

🔍 What to Watch For

✅ Expected Behavior:

  • Site ON: Activity buttons generate network requests, console messages, tokens
  • Site OFF: Activity buttons do nothing or get blocked
  • Site Re-enabled: Activity works immediately without refresh

❌ Signs of Problems:

  • Need to refresh page after re-enabling site toggle
  • Activity doesn't resume when site is re-enabled
  • Memory leaks or performance issues
