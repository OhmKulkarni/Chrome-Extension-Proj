🔒 Permission-based Library Detection Test

Testing that library detection only runs when logging permissions are enabled

📋 Test Overview

This test verifies that library detection respects user permission settings:

  • All logging disabled: Library detection should NOT run
  • Any logging enabled: Library detection SHOULD run
  • Multiple logging types: Library detection should run if any are enabled
